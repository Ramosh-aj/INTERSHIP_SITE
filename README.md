# INTERSHIP_SITE

HOW TO MAKE API:
1- انشاء التطبيق
django-admin startproject intership_site

2- تعديل الملفات: 
  - استخدام تابع لجلب بيانات الطلاب ضمن صيغة ال json
  - ربط بين المشروع  وتطبيقه عبر ال url 
  - اضافة اسم التطبيق في ال setting 

3- التحقق من ال api
  - تشغيل السيرفر
python manage.py runserver
  - الدخول على الرابط
http://127.0.0.1:8000/members/  

4- رفع التطبيق على ال github
